# 直播摘要 乾淨電腦測試清單（給 Ray，照著做、做完打勾）

測試的目的：確認「剛解壓縮、什麼都沒裝」的直播摘要，在另一台電腦（RTX 3080）、中文帳號名稱、中文路徑下，能正常使用。
每一項前面的 ☐ 做完改成 ☑（或在後面寫 O／X），做不到或看到不一樣的，在「備註」寫一句，再依「出問題時」收集資料。

**要帶過去的東西**
- `LiveSummary-v1.0.0.zip`（在這台電腦的 `dist` 資料夾，約 720 MB）
- `強制CPU測試.bat`（同一個 `dist` 資料夾；第二輪才用，**不要放進 zip**）
- 隨身碟或網路硬碟（要能放得下 zip）
- Claude 的 API 金鑰（`sk-ant-…`；測完會刪掉這台電腦裡的紀錄）

> 時間：整個測試約 1～1.5 小時，大部分是等模型下載。

## 3. 第一輪：顯示卡（RTX 3080）

### 3-1 啟動

1. ☐ 雙擊 `LiveSummary\LiveSummary.exe`。
2. ☐ 如果出現藍色「**Windows 已保護您的電腦**」→ 按「**其他資訊**」→「**仍要執行**」（這是正常的，沒簽章）。截圖留存。
3. ☐ 防毒軟體（Windows 安全性）**沒有**把程式刪掉或隔離。
4. ☐ 看到：螢幕上出現一個**浮動小膠囊**，以及「**直播摘要 使用說明**」視窗（第一次打開會自動出現）。
5. ☐ **圖示**：視窗左上角、膠囊旁沒有 Python 的預設圖示（看到紫色對話框＋播放鍵的圖示，或至少不是空白方塊）。
6. ☐ **沒有**跳出黑色的命令列視窗（一閃而過也算有問題，記下來）。

### 3-2 首次引導（共三頁）

- ☐ **第 1 頁「設定模型與金鑰」**
  - ☐ 服務選「Claude」（預設）。
  - ☐ 貼上 API 金鑰，按「**測試連線**」→ 看到綠色「連線成功，金鑰可以使用」。
  - ☐ 按「如何取得金鑰」會用瀏覽器打開官方頁面。
  - ☐ 按「下一步」。
- ☐ **第 2 頁「檢查這台電腦」**：每一行都有勾或黃色提醒，**沒有紅色叉叉**。
  - ☐ 顯示卡那一行寫「**NVIDIA 顯示卡：可即時轉錄**」。
  - ☐ ffmpeg、streamlink 那幾行是「可以」。
  - ☐ 按「下一步」。
- ☐ **第 3 頁「開始使用」**
  - ☐ 有一張說明系統匣圖示的卡片，按「**打開工作列設定**」會打開 Windows 設定的「工作列」頁面（看完關掉）。
  - ☐ 按完成，引導關閉。

### 3-3 系統匣與介面

- ☐ 右下角時鐘旁（可能收在「^」裡）找到直播摘要的小圖示（一個深色小膠囊，中間有一顆彩色的燈）。注意：這個圖示是程式畫的狀態燈，不是紫色的應用程式圖示，是設計如此。

- ☐ 點膠囊也有選單。
- ☐ 打開「設定」→ 最下面「關於」：寫「直播摘要 v1.0.0」，有 GPLv3 說明，「**打開授權清單**」按鈕能打開 licenses 資料夾。

### 3-4 第一場：Twitch（約 2 分鐘）

1. ☐ 啟動面板貼上一個**正在直播、有人講話**的 Twitch 頻道網址（中文台最好，例如：＿＿＿＿＿＿）。
2. ☐ 按「**開始**」。
3. ☐ **第一次會下載轉錄模型**（約 1.6 GB）：面板顯示下載進度（MB 數會增加），**不是卡住不動**。這一步要幾分鐘，記錄花了：＿＿＿ 分鐘。

4. ☐ 模型載好後，**約 10～30 秒內**出現第一句逐字稿（直播稿面板）。
5. ☐ 等約 **2 分鐘**，確認：
   - ☐ 直播稿面板一直有新句子，**中文是繁體字**（如果直播講簡體，輸出應轉成繁體——這是在測 OpenCC 簡轉繁；有看到簡體字殘留請截圖）。
   - ☐ 分鐘摘要有出現至少一則。
   - ☐ 聊天室面板有留言（若該台聊天室有人）。
   - ☐ 膠囊顏色/狀態有跟著變（例如「跟得上」）。
   - ☐ 沒有跳出錯誤對話框。
6. ☐ 從膠囊或系統匣選單按「**停止**」：停止後 5 秒內停下，膠囊回到「未開始」。
7. ☐ 打開「文件」資料夾 → 裡面有「**直播摘要**」資料夾，有這一場的 `…_直播稿.txt`、`…_分鐘摘要.md` 等檔案（路徑是 `C:\Users\測試小明\Documents\直播摘要`）。

## 4. 第二輪：強制 CPU 模式

目的：模擬「沒有 NVIDIA 顯示卡」的電腦。會改用 CPU 和較小的 `small` 模型（約 490 MB，會**另外下載一次**）。

1. ☐ 把 `強制CPU測試.bat` 放在 `LiveSummary` 資料夾**旁邊**（桌面上，跟 `LiveSummary` 資料夾同一層；放進 `LiveSummary` 資料夾裡也可以）。
2. ☐ **先把程式結束**（膠囊 →「結束程式」），再雙擊 `強制CPU測試.bat`（會一閃而過是正常的；它不會留下黑色視窗）。
3. ☐ 程式開啟後，打開「使用說明」（膠囊選單）→ 第 2 頁「檢查這台電腦」：顯示卡那一行是黃色「**NVIDIA 顯示卡目前無法使用：轉錄會比較慢**」（或「沒有 NVIDIA 顯示卡…」）。
4. ☐ 啟動面板貼上一個正在直播的頻道，按「開始」。
5. ☐ 面板顯示**下載 small 模型**（約 490 MB，比第一輪小）。
6. ☐ 下載完後出現逐字稿；**速度**會比顯示卡慢：看看有沒有出現「**跟不上直播**」的提示（有提示是正常的，寫在備註）。
7. ☐ 看 log 確認走的是 CPU：檔案總管網址列貼上 `%LOCALAPPDATA%\LiveSummary\logs`，打開最新的 `啟動里程碑_…txt`，找到這一行：
   `轉錄模型載入完成  | 裝置=cpu`（**必須是 cpu，不是 cuda**）。
8. ☐ 約 1～2 分鐘後按「停止」→「結束程式」。
9. ☐ 之後**正常**（不用 bat）再開一次，確認又回到顯示卡（log 寫 `裝置=cuda`）。

## 6. 出問題時要收集什麼

先**不要重開程式**，照下面拍／拷：

1. **當機紀錄**（程式出錯時會寫）：`%LOCALAPPDATA%\LiveSummary\logs\當機紀錄.txt`（裡面不會有 API 金鑰）。
2. **啟動里程碑 log**：同一個 `logs` 資料夾裡最新的 `啟動里程碑_日期_時間.txt`（記錄每一步花多久、有沒有 cuda）。
3. **整個 logs 資料夾**打成壓縮檔最保險：在 `logs` 資料夾上按右鍵 → 傳送到 → 壓縮的資料夾。
4. **要截的畫面**（`Win + Shift + S` 截圖）：
   - 錯誤對話框（整個視窗）。
   - 出問題當下的啟動面板／膠囊。
   - 首次引導第 2 頁（檢查這台電腦）。
   - 工作管理員裡的 LiveSummary、helper、ffmpeg 程序（若疑似卡住）。
   - SmartScreen 或防毒的警告畫面。
5. **寫下**：做到第幾項、看到什麼、預期看到什麼、網路狀況、當時時間。
6. 把以上全部放進一個資料夾，拷回來給我。

## 7. 測完怎麼清除

1. ☐ 先結束程式（膠囊 →「結束程式」），確認工作管理員沒有殘留。
2. ☐ **清掉認證管理員裡的 API 金鑰**（要在「測試小明」帳號裡做；金鑰是存在各帳號自己的認證管理員）：
   開始選單搜尋「**認證管理員**」→「**Windows 認證**」→「**一般認證**」→ 找名稱是「直播摘要」或結尾是「@直播摘要」的項目 → 展開 →「**移除**」。
3. ☐ 登出，改用你自己的管理員帳號。
4. ☐ **刪掉測試帳號**：開始 → 設定 → 帳戶 → 其他使用者 → 點「測試小明」→「**移除**」→「**刪除帳戶和資料**」（連同桌面、文件、程式資料一起刪）。
5. ☐ 確認 `C:\Users\測試小明` 資料夾已消失。
6. ☐（選做）如果要連模型一起清掉：轉錄模型存在使用者資料夾的 `.cache\huggingface`，刪帳戶時已一併刪除。
7. ☐ 到 Anthropic 後台（platform.claude.com → Settings → API keys），如果這把金鑰只拿來測試，**可以直接刪掉這把金鑰**。
