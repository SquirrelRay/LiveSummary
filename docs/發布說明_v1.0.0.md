# 直播摘要 v1.0.0

第一個公開版本。直播摘要會一邊聽 Twitch 或 YouTube 直播，一邊把內容轉成文字、整理成摘要；外語直播也能即時翻成中文字幕。

> [!IMPORTANT]
> **下載後請先把整個壓縮檔解壓縮，再執行！**
> 在 `LiveSummary-v1.0.0.zip` 上按右鍵 →「全部解壓縮」，再打開解壓縮出來的 `LiveSummary` 資料夾，雙擊 `LiveSummary.exe`。
> 在壓縮檔裡直接點開會打不開（出現英文的「Failed to load Python DLL」錯誤）。

## 主要功能

- **即時轉錄**：直播的聲音在你自己的電腦上轉成文字稿（Whisper，有 NVIDIA 顯示卡時用顯示卡加速）。
- **分鐘摘要**：每分鐘一兩句話整理剛剛的內容，附上聊天室的反應。
- **話題摘要**：自動判斷換話題，每個話題結束時整理成標題、重點與支線。
- **外語翻譯**：外語直播的逐句中文字幕；聊天室留言也可以翻成中文。
- **Twitch 與 YouTube**：貼上 Twitch 頻道網址或 YouTube 公開直播網址即可開始，直播時間和重播時間軸對齊。
- **名詞清單**：每位直播主一份詞庫，人名、作品名的寫法前後一致，也可以自己訂正。
- **浮動字幕與摘要**：可以疊在直播畫面上、設定成滑鼠穿透；另有精簡的浮動膠囊與系統匣選單。
- **自動存檔**：直播稿、摘要、聊天室、逐句翻譯存在「文件\直播摘要」。
- **費用估算**：啟動面板與設定裡，依目前設定顯示每小時的估算費用。
- 支援 Claude（預設）、OpenAI、Google Gemini、DeepSeek、OpenRouter 等 AI 服務，用你自己的 API 金鑰；金鑰只存在 Windows 認證管理員。
- 啟動時檢查有沒有新版本（只查版本號、不自動下載，可在設定裡關掉）。

## 系統需求

- Windows 10 或 Windows 11（64 位元）、網路連線。
- NVIDIA 顯示卡可以加速：驅動程式最低 527.41 版，建議更新到最新版。沒有 NVIDIA 顯示卡或驅動太舊時，自動改用處理器（CPU），可以用但比較慢。
- 硬碟空間：程式約 1.3 GB，加上第一次使用時下載的轉錄模型（有 NVIDIA 顯示卡約 1.6 GB，沒有約 490 MB）。
- 需要自己的 AI 服務 API 金鑰。以預設的 Claude Haiku 估算，外語直播開著翻譯一小時約 0.1 美元；中文直播更少。

## 第一次執行

- 跳出藍色的「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。本程式沒有付費的數位簽章，不代表有病毒。
- 防毒軟體誤判或刪掉檔案：請看壓縮檔裡「使用說明.txt」的常見問題。

## 已知限制

- YouTube 只支援公開的直播；會員限定、年齡限制、需要登入的直播，以及錄好的影片（VOD）、Shorts 都不支援。Twitch 的錄影檔（/videos/）也不支援。
- YouTube 聊天室只抓得到「熱門聊天」（YouTube 預先篩選過的留言），不是全部留言。
- YouTube 偶爾會要求登入驗證（判斷為機器人），這時無法開始，請稍後或換網路再試。
- YouTube 中途斷線重連過的直播，時間可能和重播進度條差幾分鐘。
- 沒有 NVIDIA 顯示卡時用 CPU 轉錄，字幕可能越來越晚。
- 摘要只靠文字稿判斷是誰說的話，合作直播時可能把別人的話算到實況主身上；話題切分的粒度也不一定穩定。
- 名詞清單只保證寫法前後一致，不保證一定正確；轉錄時就聽錯的名字沒辦法自動修正。
- 純音樂、沒人說話的直播，轉錄可能出現模型把雜音聽成話的情況。
- 沒有自動更新：Twitch／YouTube 改版造成問題時，需要下載新版。
- 目前只在少數幾款 NVIDIA 顯示卡上實測過，其他型號歡迎回報。
