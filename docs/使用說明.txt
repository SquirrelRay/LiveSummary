直播摘要（LiveSummary）使用說明

直播摘要會一邊聽 Twitch 或 YouTube 直播，一邊把內容轉成文字、整理成摘要，外語直播也可以翻成中文字幕。


一、解壓縮後怎麼開啟
  1. 在下載的壓縮檔（LiveSummary-v版本號.zip）上按右鍵 →「全部解壓縮」→「解壓縮」。
     請不要在壓縮檔裡直接點開程式，那樣一定打不開。
  2. 打開解壓縮出來的「LiveSummary」資料夾，雙擊「LiveSummary.exe」。
  3. 畫面上會出現一個浮動的小膠囊和啟動面板。第一次打開會先出現使用說明，照著三個步驟走就好。

  「LiveSummary」資料夾裡的其他檔案都是程式需要的，請整個資料夾放在一起，不要只把 LiveSummary.exe 拿出來。
  想放到別的地方（例如 D 槽），整個資料夾一起搬就可以。


二、第一次使用
  1. 申請 API 金鑰（摘要和翻譯要用線上的 AI 服務，需要自己的帳號）
     預設使用 Claude。大概的步驟：
       (1) 到 https://platform.claude.com 註冊帳號。
       (2) 在帳單（Billing）頁面儲值。服務是先儲值、用多少扣多少。
       (3) 到 https://platform.claude.com/settings/keys 建立一把金鑰，複製下來。
       (4) 回到直播摘要程式，打開程式裡的「直播摘要 使用說明」視窗（不是這份文字檔）：
           第一次打開程式時會自動出現；之後可以從膠囊或系統匣選單的「使用說明」打開。
           在第 1 頁「設定模型與金鑰」（或程式的「設定」裡）貼上金鑰，按「測試連線」。成功就會存起來。
     也可以改用 OpenAI、Google Gemini、DeepSeek、OpenRouter，步驟類似；設定裡選好服務後，「如何取得金鑰」會打開那一家的金鑰頁面。
     金鑰像一組密碼，只存在這台電腦的 Windows 認證管理員，不要給別人。

  2. 下載轉錄模型（只需要一次）
     第一次按「開始」時，程式會下載把聲音轉成文字用的模型：
       有 NVIDIA 顯示卡：約 1.6 GB
       沒有 NVIDIA 顯示卡：約 490 MB
     下載需要一點時間，啟動面板會顯示進度。下載完之後就不用再下載。


三、大概的花費
  本程式本身免費。費用來自你選的 AI 服務，依用量向你的帳號收費。
  以預設設定（Claude Haiku 模型）只做摘要來算，一小時的直播大約 0.1 美元以內；
  外語直播開逐句翻譯、或打開聊天室翻譯，每小時各再多幾美分；
  設定裡的「上網查證」打開時會明顯變多（每小時約多 0.2 美元）。
  啟動面板和設定裡會顯示依目前設定估算的每小時費用。這只是估算，實際金額以服務的帳單為準。
  以上金額是以 {版本} 發布時各服務的價格估算；服務的價格可能調整，請以程式內顯示的估算和服務的帳單為準。
  把聲音轉成文字是在你的電腦上做的，不另外收費。


四、檔案存在哪裡
  直播稿、摘要、聊天室紀錄、翻譯：「文件」資料夾裡的「直播摘要」資料夾。
    （設定框的「存檔」區有「打開存檔資料夾」按鈕；哪些內容要存檔也在那裡選。）
  程式的設定與紀錄：%LOCALAPPDATA%\LiveSummary
    （在檔案總管的網址列貼上這一串、按 Enter 就會打開。）
  轉錄模型：%USERPROFILE%\.cache\huggingface\hub


五、系統需求
  - Windows 10 或 Windows 11（64 位元）。
  - 需要網路連線（看直播、使用 AI 服務）。
  - 有 NVIDIA 顯示卡會比較快、比較準，但不是必要。沒有的話會改用處理器（CPU）轉錄，
    可以用，但比較慢，字幕可能會越來越晚。
  - 硬碟空間：程式約 1.3 GB，加上轉錄模型 0.5～1.6 GB。


六、常見問題

  ■ 出現藍色的「Windows 已保護您的電腦」
    按畫面上的「其他資訊」，再按「仍要執行」。
    原因：Windows 會對「沒有付費數位簽章」的新程式顯示這個畫面。本程式是個人開發的開放原始碼程式，
    沒有購買簽章，所以會被擋一次。這不代表程式有病毒。
    如果你不放心，可以不要執行；也可以把檔案上傳到 VirusTotal（https://www.virustotal.com）檢查。

  ■ 防毒軟體說它有病毒、或把檔案刪掉了
    沒有簽章、又是把 Python 打包成 exe 的程式，有時會被防毒軟體誤判。
    1. 確認檔案是從本程式的官方下載頁下載的。
    2. 到防毒軟體的「隔離區」把檔案還原，並把「LiveSummary」資料夾加入例外（排除項目）。
       Windows 內建的防毒：「Windows 安全性」→「病毒與威脅防護」→「保護歷程記錄」還原；
       「管理設定」→「排除項目」→ 新增資料夾。
    3. 檔案被刪過的話，請重新解壓縮整個壓縮檔。
    如果不確定，請不要執行，可以到下載頁回報。

  ■ 找不到系統匣圖示（右下角時鐘旁邊）
    Windows 11 會把新程式的圖示收進右下角的「^」裡。點「^」就看得到。
    想讓它一直顯示：設定框的「讓系統匣圖示一直顯示」按「打開工作列設定」，
    在「其他系統匣圖示」裡把「直播摘要」打開。
    浮動膠囊本身也一直都在，點一下就有選單（開始、停止、設定、使用說明、結束程式）。

  ■ 程式出錯
    程式會跳出提示，並把錯誤記在 %LOCALAPPDATA%\LiveSummary\logs\當機紀錄.txt（裡面不會有 API 金鑰）。
    回報問題時請附上這個檔案。


七、怎麼完全移除
  本程式沒有安裝到系統裡，照下面刪掉就移除乾淨：
  1. 先在膠囊選單按「結束程式」。
  2. 刪掉「LiveSummary」程式資料夾（解壓縮出來的那個資料夾）。
  3. 刪掉程式的設定與紀錄：%LOCALAPPDATA%\LiveSummary
  4. 刪掉存在這台電腦的 API 金鑰：
     開始選單搜尋「認證管理員」→「Windows 認證」→「一般認證」，
     找名稱是「直播摘要」或結尾是「@直播摘要」的項目，展開後按「移除」。
  5. （可選）刪掉轉錄模型：%USERPROFILE%\.cache\huggingface\hub 裡名稱含 faster-whisper 的資料夾。
     其他程式也可能使用這個資料夾，只刪 faster-whisper 的就好。
  6. （可選）「文件\直播摘要」是你的直播稿與摘要，要不要留由你決定。
